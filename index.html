Garmin Connect
Wichtig: Die echte automatische Synchronisation ist nicht nur Frontend-Code. Garmin stellt dafür die Garmin Connect Developer Program APIs bereit; der Zugang ist laut Garmin für Business-/Enterprise-Nutzung vorgesehen und muss beantragt/approved werden. Diese App speichert und wird niemals ein Garmin Client Secret im Frontend speichern.

Vorbereitete Architektur

Frontend → Backend → Garmin OAuth → Garmin Connect APIs
  • Strukturierte Lauf- und Kraftdaten liegen bereits im richtigen Format vor.
  • Workout-Daten lassen sich als JSON exportieren.
  • Ein späteres Backend kann OAuth 2.0 + Garmin Training API anbinden, um Workouts zu senden und Aktivitäten zu importieren.
  • Kein Garmin Client Secret darf in dieser statischen GitHub-Pages-App gespeichert werden.

Die mitgelieferte Datei garmin-integration/server-example.js zeigt die Architektur, enthält aber absichtlich keine echten Zugangsdaten.
