Garmin Connect
Wichtig: Die echte automatische Synchronisation ist nicht nur Frontend-Code. Garmin stellt dafür die Garmin Connect Developer Program APIs bereit; die Training API kann strukturierte Workouts und Trainingspläne in Garmin Connect veröffentlichen. Der Zugang ist laut Garmin für Business-/Enterprise-Nutzung vorgesehen und muss beantragt/approved werden. siehe Garmin Connect Developer Program

V2 ist dafür vorbereitet

  • Dein Plan hat strukturierte Lauf- und Kraftdaten.
  • Die App kann Workout-Daten als JSON exportieren.
  • Ein späterer Backend-Login kann OAuth 2.0 und die Garmin Training API anbinden.
  • Kein Garmin Client Secret darf in diese statische GitHub-Pages-App eingebaut werden.
Wenn Garmin freigeschaltet ist
  1. Garmin Connect Developer Program beantragen.
  2. Backend mit OAuth 2.0 erstellen.
  3. User verbindet Garmin Connect.
  4. Backend sendet Workouts/Plan über Training API.
  5. Garmin Connect synchronisiert kompatible Workouts auf die Uhr.

Die mitgelieferte Datei garmin-integration/server-example.js zeigt die Architektur, enthält aber absichtlich keine echten Zugangsdaten.
