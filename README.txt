Marathon • Calisthenics Web-App
================================

Enthalten:
- 16-Wochen-Plan bis 28.12.2026
- 2 Gym/Calisthenics-Einheiten mit Weighted Pull-ups/Dips
- 3 Lauf-Tage pro Woche
- Donnerstag/Freitag frei
- Fortschritt/Erledigt lokal im Browser
- Gewicht + Notizen
- Kalender-Export als .ics

Auf dem Handy:
1. Den Ordner online hosten (z.B. GitHub Pages, Netlify oder Vercel).
2. Die URL auf dem Smartphone öffnen.
3. "Zum Home-Bildschirm" / "Installieren" wählen.

Hinweis Garmin:
Eine direkte automatische Synchronisierung von einer privaten Web-App zu Garmin Connect erfordert Garmins Connect Developer Program/Training API. Garmin beschreibt diese Schnittstelle als Möglichkeit, Workouts und Trainingspläne nach Garmin Connect zu publizieren; sie ist für Business-Nutzung gedacht und erfordert eine Freigabe. Die App enthält deshalb bewusst den Kalender-Export statt einer vorgetäuschten Direkt-Synchronisierung.
